# راه‌اندازی سرور

این سرور هنوز برای انتشار عمومی آماده نیست. حساب و مجوزهای گام دوم اجرا شده‌اند؛ فروش، پرداخت و پذیرش مستقل هر بلیت هنوز به اصلاح نیاز دارند. اجرای محلی برای توسعه است.

راه‌اندازی دیگر جدول و داده نمونه را خودکار ایجاد نمی‌کند. نخست تغییرات ساختار اجرا شوند. فایل تغییر اولیه، ساختار فعلی ده جدول را ثبت می‌کند؛ مدل‌های پیشنهادی نسخه قدیمی هنوز در آن وارد نشده‌اند. پایگاه داده قبلی بدون بررسی ساختار، به این نسخه متصل نشود. برای پایگاه داده دارای جدول، اجرای تغییر اولیه جایگزین بررسی و تبدیل داده نیست.

## اجرای محلی

دستورها از ریشه پروژه اجرا شوند. برای این روش، اتصال پیش‌فرض یک پایگاه داده محلی تازه است. برای اتصال دیگر، متغیر محیطی نشانی پایگاه داده پیش از اجرای دستورها تنظیم شود.

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r backend/requirements.txt
.venv/Scripts/python.exe -m alembic -c backend/alembic.ini upgrade head
.venv/Scripts/python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

نشانی بررسی آمادگی سرور:

```text
http://127.0.0.1:8000/api/health
```

این مسیر اتصال و نسخه ساختار را بررسی می‌کند. اتصال ناقص یا اجرا نشدن تغییرات ساختار، پاسخ عدم آمادگی دارد.

## اجرای ظرف‌ها

در پوشه سرور، فایل نمونه تنظیمات را به فایل تنظیمات محلی کپی کنید. گذرواژه نمونه را با مقدار تصادفی طولانی شامل حروف لاتین و عدد عوض کنید؛ این مقدار در نشانی اتصال قرار می‌گیرد. فایل تنظیمات محلی در مخزن ثبت نمی‌شود.

```powershell
Copy-Item backend/.env.example backend/.env
# Edit backend/.env before starting.
docker compose --env-file backend/.env -f backend/docker-compose.yml -p gishow-dev up --build -d
```

پایگاه داده درگاه عمومی ندارد. سرور فقط روی نشانی محلی رایانه باز می‌شود. ظرف تغییر ساختار پس از آماده شدن پایگاه داده اجرا می‌شود و سرور پس از موفقیت آن شروع می‌کند. نام ثابت ظرف حذف شده تا با نمونه‌های دیگر تداخل نداشته باشد.

## بررسی خودکار

```powershell
python -m pytest backend/tests -q
```

آزمون‌ها پایگاه داده موقت می‌سازند و پایگاه داده واقعی یا پشتیبان قدیمی را تغییر نمی‌دهند. نبود اثر جانبی هنگام بارگذاری، پاسخ عدم آمادگی پیش از تغییر ساختار، اجرای دوباره تغییرات و نبود داده نمونه بررسی می‌شوند.


## رابط کاربری

از ریشه پروژه، وابستگی‌ها نصب شوند. درگاه جدا مانع تداخل با پروژه‌های دیگر است. درخواست‌های سرور از واسط همان مبدأ ارسال می‌شوند و نشست در کوکی غیرقابل خواندن برای کد صفحه ذخیره می‌شود.

```powershell
npm ci
npm run dev -- --port 5173 --strictPort --host 127.0.0.1
```

## مدیر اولیه

مدیر اولیه از مسیر عمومی ساخته نمی‌شود. پس از اجرای تغییرات ساختار، دستور زیر در ترمینال اجرا شود؛ شماره و نام نمونه با اطلاعات مدیر جایگزین شوند. گذرواژه در ترمینال بدون نمایش وارد می‌شود. کدهای بازیابی فقط یک‌بار نمایش داده می‌شوند. اگر مدیر موجود باشد، دستور از جایگزینی حساب جلوگیری می‌کند.

```powershell
docker compose --env-file backend/.env -f backend/docker-compose.yml -p gishow-dev exec api python -m backend.bootstrap_admin --mobile 09100000000 --name "مدیر سامانه"
```

در نمونه توسعه همین شاخه، مدیر محلی ساخته شده و اطلاعات ورود در فایل خصوصی داخل پوشه بررسی محلی نگهداری می‌شود. این فایل در مخزن یا تصویر ظرف وارد نمی‌شود. حساب موقت بررسی مرورگر پس از آزمون پاک می‌شود.

برای میزبانی امن، کوکی امن فعال شود و مبدأهای مجاز دقیقاً مطابق نشانی واقعی سایت تنظیم شوند. تنظیم نامحدود مبدأ پذیرفته نمی‌شود.

```text
COOKIE_SECURE=true
CORS_ORIGINS=https://your-site.example
```
