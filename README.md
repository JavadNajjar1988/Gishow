# لیندو تیکت؛ بازسازی گیشو

این مخزن شامل رابط مرورگر و سرور فروش بلیت در حال بازسازی است. بخش‌های عملیاتی فعلی: حساب و دسترسی، مدیریت سالن و پلان، مدیریت برنامه و ساخت سانس، نمایش عمومی برنامه منتشرشده و موجودی صندلی. پرداخت واقعی و انتقال داده‌های نسخه قدیمی هنوز کامل نشده‌اند.

## اجرای رابط

مبنای نصب، فایل قفل بسته‌های موجود در مخزن است:

```powershell
npm ci
npm run dev -- --port 5173
```

مسیر درخواست‌های هم‌مبدأ به سرور محلی هدایت می‌شود. مقصد پیش‌فرض و متغیر تغییر آن این‌ها هستند:

```text
/api
http://127.0.0.1:8000
API_PROXY_TARGET
```

## اجرای سرور و بررسی‌ها

تنظیم محیط و ساخت مدیر نخست در [راهنمای حساب و دسترسی](docs/account-access-fa.md) آمده است. وارد کردن ماژول سرور پایگاه داده را ایجاد نمی‌کند؛ تغییر ساختار باید قبل از اجرا اعمال شود. روش داکر موجود همین ترتیب را اجرا می‌کند.

```powershell
python -m pip install -r backend/requirements.txt
python -m alembic -c backend/alembic.ini upgrade head
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

نشانی رابط در فهرست مبدأهای مجاز سرور باید ثبت شده باشد. از انتشار فایل محیط، گذرواژه، کد بازیابی، پایگاه داده محلی و پشتیبان جلوگیری کنید.

```powershell
npm run lint
npm run build
python -m pytest backend/tests -q
```

آزمون‌ها پایگاه داده موقت می‌سازند. روش بررسی روی پایگاه داده سرور در کد آزمون حساب‌ها تعریف شده و برای هر آزمون ساختار خصوصی می‌سازد.
